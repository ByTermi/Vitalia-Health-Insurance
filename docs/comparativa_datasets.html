Veredicto: usar el stack propio (UCI HAR + MotionSense + PAMAP2 + MobiAct + SisFall)

DSADS usa 5 unidades Xsens corporales (no smartphone), solo 25 Hz, 8 sujetos, sin caídas y ciclismo en bici estática. No aplica para inferencia on-device en smartphone. Nuestro stack cubre todos los requisitos del enunciado con datos de smartphone real a 50 Hz y 66–180 sujetos.

Stack propio — qué cubre cada dataset

UCI HAR #240
30 sujetos · 50 Hz · Smartphone cintura · UCI ML Repo
  • Caminando, corriendo
  • Subir / bajar escaleras
  • Sentado, parado, tumbado
  • Baseline de referencia del campo (benchmark)
Fundamento del modelo HAR. Permite comparar con papers publicados directamente.
MotionSense
24 sujetos · 50 Hz · Smartphone bolsillo · GitHub
  • Mismo placement que usuario real (bolsillo)
  • Caminar, correr, escaleras, sentado, parado
  • Robustez de colocación junto con UCI HAR
Añade variabilidad de placement (cintura UCI vs bolsillo MotionSense) para cubrir R2.
PAMAP2 #231
9 sujetos · 100 Hz → 50 Hz · Body-worn · UCI ML Repo
  • Correr exterior (ritmo libre)
  • Ciclismo real (único dataset con bici exterior)
  • Actividades adicionales para riqueza de señal
El enunciado exige ciclismo real. DSADS solo tiene bici estática. PAMAP2 es la única opción.
MobiAct v2
66 sujetos · ~87 Hz → 50 Hz · Smartphone bolsillo · BMI HMU
  • 4 tipos de caída: FOL, BSC, SDL, SIS (síncope)
  • 12 actividades ADL como negativo del detector
  • Mayor dataset de caídas con smartphone
Pilar principal del fall detector. 66 sujetos permiten LOSO robusto. Mismo hardware (smartphone bolsillo) que el target.
SisFall
38 sujetos (15 ancianos 60-75) · 200 Hz → 50 Hz · Cintura · PMC
  • 15 tipos de caída + 12 ADL
  • 15 sujetos de 60-75 años (ancianos reales)
  • Caídas más lentas y suaves (patrón diferente al adulto joven)
El enunciado enfatiza el segmento 65+. SisFall es el único dataset público con sujetos ancianos reales. Diferenciador clave frente a la competencia.
