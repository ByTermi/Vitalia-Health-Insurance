Gestión del riesgo
Cada asegurado tiene su configuración
No existe una sensibilidad perfecta para todos — Vitalia la ajusta automáticamente según el perfil de la póliza
💀 Caída no detectada
El sistema no genera alerta ante una caída real
→ El anciano queda sin asistencia
→ Riesgo vital · Responsabilidad para Vitalia
🔔 Falsa alarma
El sistema genera alerta sin que haya caída
→ Alarma innecesaria a la familia
→ Desconfianza → el usuario desinstala la app
🏥 Máxima seguridad (65+)
Muy sensible
No se pierde ninguna caída · Puede haber alguna falsa alarma · Para asegurados de mayor riesgo
⚖️ Equilibrado (45–65)
Balanceado
Alta detección con pocas falsas alarmas · Perfil de adulto activo
🎯 Tranquilidad (<45)
Conservador
Solo alerta en caídas claras · Mínimas interrupciones · Para usuarios jóvenes activos
✨ Sin reprogramar nada — Vitalia cambia la sensibilidad desde el perfil de la póliza
El médico de cabecera o el propio asegurado puede ajustar el nivel. Además, el sistema siempre pregunta "¿Estás bien?" antes de avisar a la familia — eliminando falsas alarmas sin perder detecciones reales.
